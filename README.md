## 📦 Cómo usar estos archivos

### Opción 1: Hosting tradicional (Recomendado)

1. **Sube los archivos a tu hosting:**
   - Accede al panel de control de tu hosting (cPanel, Plesk, etc.)
   - Ve al File Manager o usa FTP
   - Sube los 3 archivos a la carpeta `public_html` o `www`

2. **Proveedores recomendados:**
   - **Hostinger** - Desde $2.99/mes
   - **SiteGround** - Excelente soporte
   - **DonWeb** (Argentina) - Pago en pesos
   - **GitHub Pages** - GRATIS (ideal para comenzar)

### Opción 2: GitHub Pages (GRATIS)

1. Crea una cuenta en [GitHub](https://github.com)
2. Crea un nuevo repositorio
3. Sube los 3 archivos
4. Ve a Settings > Pages
5. Activa GitHub Pages
6. ¡Tu sitio estará en `username.github.io/nombre-repo`!

### Opción 3: Netlify/Vercel (GRATIS)

1. Crea cuenta en [Netlify](https://netlify.com) o [Vercel](https://vercel.com)
2. Arrastra y suelta los archivos
3. ¡Listo! Tendrás un URL automático
4. Puedes conectar tu dominio propio

## 🌐 Dominio propio

Para usar tu dominio labeltech.com.ar:

1. **En tu proveedor de dominio** (NIC Argentina):
   - Ve a configuración DNS
   - Apunta los registros A a la IP de tu hosting
   - Espera 24-48 horas para propagación

2. **En tu hosting:**
   - Agrega el dominio en el panel de control
   - Configura certificado SSL (HTTPS)

## ✏️ Personalización

### Cambiar textos
Abre `index.html` y edita los textos directamente. Son fáciles de identificar.

### Cambiar colores
En `styles.css`, las primeras líneas tienen las variables de color:
```css
:root {
    --primary: #0F172A;
    --accent: #3B82F6;
    /* Cambia estos valores */
}
```

### Agregar imágenes
1. Crea una carpeta `images` junto a los archivos
2. Sube tus imágenes
3. Reemplaza los placeholders SVG con:
   ```html
   <img src="images/tu-imagen.jpg" alt="Descripción">
   ```
